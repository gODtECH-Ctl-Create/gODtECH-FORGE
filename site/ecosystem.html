BOUNDARIES

One project. Different responsibilities.

01

Before building

FORGE can inspect the project and prepare bounded context. StackPilot can generate or adopt a supported project foundation.

02

While building

FORGE governs task flow, approvals, runs, and evidence. The coding client remains responsible for model execution.

03

After changes

Steward can independently scan repository health and produce findings that can optionally feed a FORGE verification workflow.

Integration rule: FORGE may call Steward through public CLI and machine-readable contracts when repository health is relevant. StackPilot may consume Steward's versioned scan report observationally. Neither integration changes the owning product's core responsibility, and neither makes Steward or StackPilot a runtime prerequisite for FORGE.
