# FORGE v0.7.0 - Benchmark Evidence and Task Classification

FORGE v0.7.0 brings learning from external DeployGuard work into task classification and publishes the completed exploratory benchmark phase.

## Product improvement

- Feature-intent tasks such as "Add incident CRUD endpoints and dashboard workflow" are classified as feature work instead of being treated as bugs because they contain "incident".
- Explicit incident outage/failure fixes remain bug work, with regression coverage for both cases.
- Existing CLI commands, MCP support, Codex integration, and banner controls remain available. This release preparation changes no dependencies or installation interfaces.

## Public evidence

The repository now records DG-BM-001 through DG-BM-005: incident CRUD, authentication/security, database audit changes, GitHub Actions CI/CD, and Kubernetes deployment manifests and probes.

See the [benchmark phase summary](https://github.com/gODtECH-Ctl-Create/gODtECH-FORGE/blob/v0.7.0/forge/evidence/benchmark-phase-summary.md) for outcomes and limitations. These are exploratory results, not a completed controlled comparison. Kubernetes manifests do not establish live-cluster runtime verification.

FORGE's context estimates are not provider token or credit measurements. This release makes no percentage claim about AI credit savings. Controlled runs from identical baselines with equivalent verification and provider telemetry remain the next evidence milestone.

## Distribution and compatibility

- Runtime: Node.js 20+.
- License: Apache-2.0.
- No project migration is introduced by this release preparation.
- The release workflow validates metadata, signed tag ancestry, tests, packed installation, checksums, and provenance before publication. Existing release tags remain unchanged.

After the v0.7.0 release is published, install using its versioned assets:

Linux/macOS:

```bash
curl -fsSLO https://github.com/gODtECH-Ctl-Create/gODtECH-FORGE/releases/download/v0.7.0/install.sh
sh install.sh 0.7.0
forge --version
```

Windows PowerShell:

```powershell
Invoke-WebRequest https://github.com/gODtECH-Ctl-Create/gODtECH-FORGE/releases/download/v0.7.0/install.ps1 -OutFile install.ps1
.\install.ps1 -Version 0.7.0
forge --version
```

If local PowerShell policy blocks the downloaded script, review it first and, where organizational policy permits, use `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that session before running it. This does not change machine-wide policy.
