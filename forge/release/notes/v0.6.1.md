# FORGE v0.6.1 — Shared gODtECH CLI Identity

FORGE v0.6.1 is a focused patch release that adds the shared gODtECH terminal identity to interactive FORGE usage.

## What changed

- integrate the canonical gODtECH CLI Identity package
- show the FORGE identity for interactive human-readable commands
- preserve clean machine-readable and automation output
- suppress decorative output for JSON, version, MCP server, piped/non-TTY, and explicitly disabled banner modes
- support `FORGE_NO_BANNER=1` and `FORGE_ASCII=1`
- pin the finalized CLI Identity packaging commit so the shared runtime ships reliably

## Output safety

The identity is intentionally presentation-only. Existing automation-safe behavior remains unchanged: structured output, version output, MCP serving, and non-interactive pipelines do not receive the decorative banner.

## Verified release distribution

The existing FORGE release pipeline continues to verify version consistency, require a signed annotated release tag, confirm main-branch ancestry, run type checking and the complete test suite, smoke-test the packed CLI, generate checksums, create Sigstore-backed provenance attestations, and publish immutable release assets.
