# Core Policies

These rules apply across FORGE and should not be weakened for convenience.

- Understand intent before implementation.
- Inspect existing code and context before making architectural changes.
- Challenge unnecessary scope and complexity.
- Prefer root-cause fixes.
- Keep project context and implementation consistent.
- Never expose secrets or bypass security controls.
- Do not declare work complete without applicable verification.
- Separate guidance from enforcement: objective checks belong in tooling.
